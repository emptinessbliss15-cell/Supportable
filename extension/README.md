# Supportable Chrome Extension

The Supportable Chrome extension uses Chrome's side panel as its primary UI.

## Load locally

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked**.
4. Select this `extension/` directory.
5. Pin Supportable and click its toolbar icon.

The side panel stays associated with the current webpage. Screen video capture uses Chrome tab capture and stores the resulting recording locally until it is attached to a support request.
